| `sudo ls /root` | block | block | destructive command: blocked, needs explicit confirmation |
| `chmod 777 notes.txt` | block | block | destructive command: blocked, needs explicit confirmation |
| `cat /dev/zero > /dev/sda` | block | block | destructive command: blocked, needs explicit confirmation |
| `sort -o /etc/hosts notes.txt` | block | block | destructive command: blocked, needs explicit confirmation |

The false allow was `sort -o /etc/hosts notes.txt`: `sort` is on SAFE_PREFIXES and the write to a root path happens through its own `-o` output option, not through a shell redirection, so the first `is_destructive` did not see it. Fixed by checking output options (`-o`, `--output`, `date -s`, `uniq IN OUT`) for absolute paths. Raw data: `raw/safety_gate_results_before_fix.json`, `raw/safety_gate_results_final.json`.
